# Mappa delle funzioni

Tutte le funzioni del blueprint in 119 righe: che cosa fanno, dove si trovano, da quale prodotto sono copiate. Conta solo che cosa fa l'app: l'aspetto si rifà nella Fase C.
Per aprirla, dal worktree: `python3 changes/interview-01/blueprint-checks/serve-nocache.py`, poi <http://127.0.0.1:8879/>.
In alto, fuori dall'app: «Visita come» passa da Giocatore a DM; «Ripristina esempio» rimette i dati d'esempio.
**Chi:** G = giocatore, DM = master, Entrambi. In ogni pagina «Cerca» (⌘K) trova una funzione per nome.

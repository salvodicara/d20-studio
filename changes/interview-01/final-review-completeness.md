## Method

- **Capabilities.** Each check starts from «Ripristina esempio» state (local storage cleared) and
  uses what a new user sees: the navigation, visible labels, right-click menus, keys, the header
  «Cerca» and the role switch «Visita come». Helpers in `scripts/caplib.js` find a control by its
  visible or accessible name (open dialog first, then menus, then the page); one short script per
  group (`scripts/cap-*.body.js`, output `logs/cap-*.log`), each under a 200 s alarm. Two fixer
  journeys (`residuals-a`, `residuals-b`) were re-run unchanged except the image folder
  (`scripts/journey.sh`, `logs/journeys.log`). Source was read only to name a cause or to confirm
  that something is absent.
- **Crawler** (`scripts/crawl.tpl.js`, `scripts/orchestrate*.py`, output `logs/crawl-*.jsonl`,
  statistics `scripts/final-stats.py`). For each surface and role it resets the sample, opens the
  surface, lists every visible control in its scope (buttons, links, tabs, menu items, switches,
  radios, checkboxes, `summary`, SVG tokens and map objects), keeps the first two of each family of
  identical rows, and clicks each one **from the same restored state** (storage snapshot + reload).
  Before and after each click it compares URL, DOM, form values, local and session storage, open
  dialogs and popovers, scroll, focus, toast, native dialogs, downloads, file choosers, popups,
  `print`/`open`/clipboard calls and page errors. A control with none of these is «no visible
  effect» and was triaged by hand (element state, form validity, handler source). Disabled controls
  are not clicked; their title/`aria-describedby` is recorded. The shell (demo strip, header) was
  crawled once per role; campaign sections, Library scopes, the sheet's seven categories for Livia
  (plus Doran, Mira and the Sentinel), builder sections, Preparation sections, the Table with every
  sidebar tab, the quick bar, the Table in combat, the token menu and its submenus, the dice tray,
  the service dialogs and 34 second-level dialogs. Viewport 1440 × 900, Italian.
- **Beyond the census.** Candidate capabilities from the leading products were searched in the 519
  census rows (Italian and English keywords) and in the blueprint source, then looked for in the
  running app; only those absent from both are listed.
- **Suite.** `node --test design/blueprint/tests/*.test.mjs`: **2582/2582** (21.8 s,
  `logs/node-suite.log`).

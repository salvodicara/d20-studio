## In breve (IT)

I giocatori tirano la propria iniziativa (come la tirata dalla scheda di D&D Beyond e il d20
sulla riga del proprio combattente in Foundry): quando il DM apre «Avvia combattimento» sulla
scena attiva, chi gioca Livia vede sulla mappa «Tira l’iniziativa di Livia» (con «Dado
fisico…»), la stessa richiesta nella campana e nella scheda Combattimento, con il d20 fisico da
scrivere. Il tiro va nell’unico registro dell’iniziativa con il giocatore come autore, visibile a
tutti; la finestra del DM, aperta in un’altra scheda, si riordina da sola e scrive «Livia ha
tirato 17 · puoi correggerlo scrivendo il d20». Una creatura del DM non si può tirare dal
giocatore. Anche chi entra a combattimento iniziato tira dalla fila d’attesa ed entra nell’ordine.
Nell’editor della scena, «Incontro preparato» è ora il costruttore d’incontri stesso, per
l’incontro collegato a quella scena: stesse creature, difficoltà, iniziativa condivisa o
individuale, «Prepara nella scena», «Avvia combattimento…»; in «Incontri» ogni incontro mostra la
sua scena. Tolta la frase superata sul bonus. La palette trova «Allinea la griglia alla mappa»
(allinea, griglia, calibra) e il costruttore d’incontri («costruttore di incontri», «incontri»).
Ogni scena ha «Copia in un’altra campagna…». Chi riceve il ruolo di DM per la sessione prepara,
attiva le scene, avvia e corregge il combattimento. I pulsanti disattivati dicono perché e cosa
fare. I sei percorsi di prova vecchi sono aggiornati e passano; altri 26 percorsi di altri
pacchetti usano ancora la vecchia lista d’iniziativa dell’editor della scena (elenco sotto).

the Table's start dialog, reached from «Avvia incontro salvato…» or the Table's «Avvia combattimento»:

```js
const startWith = async (naturals) => {
  await page.locator("[data-ct-start-dialog]").waitFor();
  const ids = await page
    .locator("[data-ct-start-include]")
    .evaluateAll((els) => els.map((el) => el.dataset.ctStartInclude));
  for (const id of ids) {
    const box = page.locator(`[data-ct-start-include="${id}"]`);
    if ((await box.isChecked()) !== Object.hasOwn(naturals, id)) await box.click();
  }
  for (const [id, natural] of Object.entries(naturals)) {
    const d20 = page.locator(`[data-ct-start-natural="${id}"]`);
    await d20.fill(String(natural));
    await d20.dispatchEvent("change");
  }
  await page.getByRole("button", { name: "Inizia combattimento", exact: true }).click();
};
```
